# Task 5: Wireshark Network Traffic Analysis

## 📌 Objective
Capture and analyze network traffic using Wireshark to identify common protocols and understand basic network communication.

## 🛠️ Tools Used
- Wireshark
- Windows
- Ping and DNS lookup utilities

## 🔍 Protocols Analyzed
- **DNS:** Observed domain-name queries and responses.
- **TCP:** Examined TCP communication, acknowledgements, and traffic involving port 443.
- **ICMP:** Observed Echo Request and Echo Reply packets during connectivity testing.
- **TLS:** Identified encrypted traffic associated with secure web communication.

## 🧪 Practical Work
- Captured live network packets.
- Applied Wireshark display filters: `dns`, `tcp`, `icmp`, and `tls`.
- Inspected packet details and protocol information.
- Documented observations in a technical report.

- How DNS resolves domain names.

- How ICMP helps test connectivity.
- How Wireshark filters help investigate network traffic.
